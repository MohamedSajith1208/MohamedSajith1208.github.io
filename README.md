# Mohamed Sajith A — Career Portfolio

A responsive, dark technical portfolio built with plain HTML, CSS, and JavaScript. No build tools or paid hosting are required.

## Files

- `index.html` — page content and career sections
- `assets/css/style.css` — responsive design and visual styling
- `assets/js/main.js` — mobile navigation, current year, and contact-button setup

## Preview on your Mac

1. Download and unzip the portfolio folder.
2. Open the folder in VS Code.
3. Open `index.html` in your browser. You can also use VS Code's Live Server extension if you have it installed.

## Personalize before publishing

1. Open `index.html` and check job titles, company names, dates, and skill descriptions against your official records.
2. In `assets/js/main.js`, set `CONTACT_EMAIL` to your professional email. Do not put a private/personal email here unless you want it public.
3. Add your LinkedIn URL when you are ready. The page currently links to the GitHub username supplied for this project: `MohamedSajith1208`.
4. Add a PDF resume only after you have reviewed it. If you add `resume.pdf`, you can add a download link to the hero section.
5. Do not publish internal hostnames, IPs, screenshots, customer information, license keys, VPN details, or company-confidential documents.

## Publish free with GitHub Pages

GitHub Pages can host static HTML/CSS/JavaScript from a repository. For a personal site, GitHub's documented convention is a repository named `MohamedSajith1208.github.io`.

1. Sign in to GitHub as `MohamedSajith1208`.
2. Create a **public** repository named exactly `MohamedSajith1208.github.io`.
3. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root, not inside an extra nested folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then save.
7. Wait for the Pages deployment to finish. Your expected address will be `https://MohamedSajith1208.github.io/` (GitHub usernames and URLs are generally treated case-insensitively).
8. If the site does not appear immediately, check the Pages section and the repository's Actions tab for deployment status.

Official instructions: https://docs.github.com/en/pages/quickstart
